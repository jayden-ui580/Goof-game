# Goof Game

Roblox game project.

- [`HairPhysics/`](HairPhysics/README.md) — rigged physics hair for the R15 rigs MrPigtails and MrLady, a sealed test arena that fills with flowing terrain water (Z opens a drain hole), and a roam test script.
- [`DragonWish/`](DragonWish/README.md) — Dragon Wish: Online. Players morph into the Base rig with rigged spiky hair and belt; R + spamming Space charges an aura (hair and belt blown upward) and bursts into Super Saiyan.
